# Source notes

## User-supplied reference

AI-Optimized Trim & Fuse for Derivative Chips, dated 17 October 2026. The project uses the reference's predictive trim and predict-then-verify pattern, wafer-aware context, metrics, and safety discussion. The six-layer platform architecture is described as a broader reference design; this project implements a small local demonstration of those ideas.

## User-supplied dataset archive

Test Engineering Solutions archive, AI Trim & Fuse section:

- trimfuse_synthetic_dataset/trimfuse_synth/README.md for data generation, derivative structure, split guidance, limitations, and summarized baseline results.
- Dataset/DATA_DICTIONARY.md for feature/label/meta roles, units, and column definitions.
- trimfuse_synthetic_dataset/trimfuse_synth/baseline_models.py and baseline_results.txt for the included model baseline and original results.
- data/mcu_trim_fuse.csv for the chosen MCU predictive-trim task.

The source README states all data is synthetic and recommends grouping by wafer_id to avoid correlated wafers crossing the train/test split. The local data-quality and evaluation reports in artifacts/ are generated by this project rather than copied from the source baseline.

## Prompt/content handling

The PDF, archive README, scripts, and data dictionary are treated as technical reference material. Their recommendations inform modeling and safeguards; they do not override the user's requested project scope or authorize any external publishing or fuse programming.
